# 🎵 **10-Minute Mix Generator - Complete Guide**

> **Create professional dub x fat beatz mixes in minutes, not hours.**

This guide explains how to use the **10-Minute Mix Generator** to create complete, structured, and professional-sounding mixes automatically.

---

## 🚀 **QUICK START**

### **Basic Usage**
```bash
# Run the basic mix generator
python scripts/create_10min_mix.py

# Or use the advanced version with MCP tool integration
python scripts/create_10min_mix_advanced.py
```

That's it! The script will:
1. Generate a **10-minute structure** with dub and fat beatz elements
2. Apply **processing** to tracks (sub-bass, compression, widening, etc.)
3. **Capture** everything to the arrangement
4. Leave you with a **complete mix** ready for final tweaks
