## 🚀 **LOADING INSTRUMENTS IN ABLETON LIVE (STEP-BY-STEP)**

### **STEP 1: Open the Project**
1. Open Ableton Live 12.4.3
2. File → Open → Select `Roots_Reggae_Mix_with_MIDI.als`
3. Project loads with 8-10 tracks and MIDI content

### **STEP 2: Load Instruments (Track by Track)**

#### **Track 0 (Kick)**:
1. Click the track area
2. Press **CMD+T** (Mac) or **Ctrl+T** (Windows)
3. Select **"Drum Rack"** from instruments
4. Load reggae kick samples into the rack
5. Adjust tuning to ~100Hz for one-drop weight

#### **Track 1 (Bass)**:
1. Click the track area
2. Press **CMD+T** / **Ctrl+T**
3. Select **"Operator"**
4. Set to **Sine** wave mode
5. Cutoff frequency ~200Hz
6. Optional: Add **Compressor** for sub weight

#### **Track 2 (Snare)**:
1. Add **"Drum Rack"** or **"Impulse"**
2. Load tight, dry snare sample
3. Place snares on beats 2 & 4

#### **Track 3 (Hi-Hats)**:
1. Add **"Drum Rack"** with dark hi-hat samples
2. Velocity 70-85 for rhythm support

#### **Track 4-9 (Other instruments)**:
1. Follow same process
2. Load appropriate instruments from above list
3. Adjust settings as per technique guidelines

### **STEP 3: Configure Effects (Optional)**

```
KICK: Compressor (+4dB gain), EQ Eight (low cut @ 80Hz)
BASS: Compressor (3:1 ratio), EQ Eight (low pass @ 200Hz)
GUITAR: Compressor (2:1 ratio), Delay (1/4 note, 30% feedback)
ORGAN: Compressor, Chorus Ensemble (5Hz rate, 40% depth)
VOCAL: Compressor (3:1), Delay (dub echo, 60% feedback), Reverb (3s)
```
