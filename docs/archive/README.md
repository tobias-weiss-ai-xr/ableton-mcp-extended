# Archived notes

Historical working notes: AI session summaries, feature-announcement write-ups and
inventory dumps produced while building this project. They are kept because they
record how decisions were made, **not** because they describe the current code.

Nothing here is maintained, linked from the main docs, or verified against `main`.
For the current state, read:

- `README.md` — what the project is and how to run it
- `AGENTS.md` — architecture rules and the commands that actually exist
- `docs/arc42/` — the maintained architecture documentation
- `docs/TOOLS.md` — generated tool reference
- `QUICK_START.md`, `PIPELINEREADME.md`, `QUICK_REFERENCE.md` — working guides
