## 🔧 **TROUBLESHOOTING**

### **Common Issues & Solutions**

| Issue | Check | Solution |
|-------|-------|----------|
| **Connection Failed** | Ableton running? | Start Ableton with Remote Script |
| **No Scenes Found** | Scenes exist? | Create scenes or use `setup` |
| **Locators Not Created** | Too many locators? | Delete existing, recreate |
| **Playback Not Starting** | Transport stopped? | Stop playback first, then start |
| **Tracks Too Loud** | Volume levels | Run `polish_suite.py balance` |

### **Error Handling**
All scripts include:
- Automatic reconnection on connection drop
- Timeout protection (30s default, 60s for long ops)
- Graceful degradation on errors
- Clear, actionable error messages
