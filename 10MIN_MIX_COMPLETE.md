## 🎯 **WHAT IS THE 10-MINUTE MIX GENERATOR?**

The **10-Minute Mix Generator** is a **production automation tool** that creates complete, structured musical arrangements by:

1. **Generating** a sophisticated mix structure with dub and fat beatz elements
2. **Applying** professional processing (dub effects + fat beatz) to tracks
3. **Capturing** all scenes to Ableton's arrangement view
4. **Creating** locators and markers for easy navigation

The result is a **fully-formed 10-minute mix** that sounds professional and is ready for final tweaks or immediate export.

### **Step 1: Install Dependencies**
```bash

cd ableton-mcp-extended

# Install requirements (if not already installed)
pip install -r requirements.txt
```

### **Step 2: Install Remote Script**
Copy the `AbletonMCP_Remote_Script` folder to:
- **Windows**: `C:\Users\[YourName]\Documents\Ableton\User Library\Remote Scripts\`
- **Mac**: `/Users/[YourName]/Documents/Ableton/User Library/Remote Scripts/`

### **Step 3: Configure Ableton**
1. Open Ableton Live
2. Go to **Preferences → Link/Tempo/MIDI**
3. Under **Control Surfaces**, add **AbletonMCP**
4. Ensure **Track**, **Sync**, and **Remote** are all turned **ON**
5. Set **Input** and **Output** to your network interface

### **Step 4: Start MCP Server**
```bash
# Start the MCP server
python -m MCP_Server.server
```

## 🔍 **TROUBLESHOOTING**

### **Problem: Connection Failed**
**Symptoms**: `Error connecting to MCP Server`

**Solutions:**
1. Make sure **Ableton is running**
2. Make sure **Remote Script is installed**
3. Make sure **MCP Server is started**: `python -m MCP_Server.server`
4. Check **firewall settings** (port 9877 must be open)
5. Verify **network connection** (try `localhost` or `127.0.0.1`)

### **Problem: Scenes Not Triggering**
**Symptoms**: Scenes don't play when triggered

**Solutions:**
1. Check **scene launch mode** (set to **Trigger**)
2. Check **scene launch quantization** (set to **None** or **1 bar**)
3. Make sure scenes **contain clips**
4. Check that **tracks are armed**

### **Problem: No Sound in Arrangement**
**Symptoms**: Arrangement is empty or silent

**Solutions:**
1. Check that **recording was enabled** during capture
2. Verify that **tracks were armed**
3. Check **input monitoring** settings
4. Make sure **clips exist** in scenes
5. Verify **playback position** is within recorded material

### **Problem: Missing Tools**
**Symptoms**: `Tool not found` or `Tool not registered`

**Solutions:**
1. Make sure **MCP Server is started** with all tools
2. Check **server.py** has all imports
3. Verify **no Python errors** during server startup
4. Restart **MCP Server**

### **Problem: BPM Changes Not Working**
**Symptoms**: BPM stays constant

**Solutions:**
1. Make sure **tempo changes** are in the structure
2. Check **Ableton's tempo automation**
3. Verify **tempo range** in structure is varied

### **Problem: Processing Not Applied**
**Symptoms**: Effects not visible on tracks

**Solutions:**
1. Check **track indices** match your set
2. Verify **devices are loaded** correctly
3. Check **parameter ranges** are valid
4. Manually verify **one tool** works before full mix

### **Problem: CPU Overload**
**Symptoms**: Ableton freezes or crashes

**Solutions:**
1. Reduce **reverb decay times**
2. Lower **echo feedback** amounts
3. Use **fewer simultaneous effects**
4. **Bounce tracks** to audio and disable plugins
5. **Freeze tracks** with heavy processing

## 🎯 **FREQUENTLY ASKED QUESTIONS**

### **Q: How do I know if it worked?**
Check Ableton's arrangement view. You should see:
- **Extensive arrangement** with all scenes captured
- **Locators** at section boundaries
- **Automation lanes** with effects
- **Device racks** on tracks

### **Q: Can I use this for live performance?**
Yes! The mix can be:
- **Triggered live** from Session View
- **Used as backing track**
- **Mixed with live elements**
- **Further automated** with follow actions

### **Q: Can I export to audio?**
Yes! After generation:
1. Set **output level** to -6dB for headroom
2. Check **mono compatibility**
3. Use **File → Export Audio** in Ableton
4. Export as **WAV 44.1kHz 24-bit**

### **Q: Can I modify the mix after generation?**
Absolutely! The generator:
- Creates **non-destructive** processing
- All **parameters are editable**
- All **clips and scenes remain**
- You can **manually tweak** everything

### **Q: What if I don't have 8 scenes?**
The generator will:
- Use **available scenes**
- **Reuse scenes** where necessary
- **Warn you** about missing scenes
- Still create a **complete mix**

### **Q: Can I use this with MIDI controllers?**
Yes! After generation:
- **Map controls** to device parameters
- **Use follow actions** for hands-free operation
- **Create custom mappings** for live performance

### **Q: Does this work with Suite plugins?**
Yes! The generator:
- Works with **any Ableton devices**
- Can use **third-party plugins**
- Works with **Max for Live** devices
- Accepts **any audio/MIDI tracks**

### **Q: Can I create mixes longer than 10 minutes?**
Yes! Modify the structure:
- Add **more sections**
- Extend **section lengths**
- Repeat **patterns**
- The generator **scales automatically**
