### **MIDI Humanization Engine**

```python
def humanize(time, velocity, duration, variation=0.12):
    return {
        'time': time + random(-variation, variation),
        'velocity': velocity * random(0.85, 1.15),
        'duration': duration * random(0.8, 1.2)
    }
```

**Humanization Features:**
- **Velocity variation**: ±10-15% for natural feel
- **Timing variation**: ±0.12 beats for groove
- **Duration variation**: ±20% for natural decay
- **Genre-specific**: Variation levels per genre character

## 🎓 **PRODUCTION TIPS BY COMPONENT**

### **Drum Mixing**
```
Kick: HPF 80Hz, light compression
Snare: Body 200-300Hz， high 5-8kHz
Hi-hats: HPF 1kHz，stereo spread
Percussion: Light compression 2:1
```

### **Bass Processing**
```
EQ HPF 40Hz, low-mid boost +4dB @ 150Hz
Mid cut -2dB @ 300Hz
High-cut -6dB @ 2kHz
Compression 3:1，threshold -12dB
Sub bass layer (parallel)
Saturation (20% drive)
Sidechain (kick to bass)
```

### **Effects Processing**
```
Echo: Time 1/4-1/2 note，feedback 40-85%，mix 25-50%
Reverb: Decay 2-10s，mix 15-30%
Filter: LFO automation 0.5-5Hz
Compression 2-4 ratio depending on genre
```

### **Master Chain**
```
1. Stereo imaging (width control)
2. Multiband compression (frequency balance)
3. EQ (final shaping)
4. Limiter (LUFS target -14 to -8dB)
```
