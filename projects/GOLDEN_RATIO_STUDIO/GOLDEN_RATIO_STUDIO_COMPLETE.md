## 🎛️ **GENRE-SPECIFIC PRODUCTION TECHNIQUES**

### **1. DUB REGGAE (78 BPM, C Minor)**

**Characteristics:**
- **One Drop Rhythm**: Kick on beat 1 only (classic reggae)
- **Dub Bass**: C minor with sub-bass layers, inverted variations
- **Golden Ratio**: 78 BPM × φ = 126 BPM (connected to house tempo)
- **Key Instrument**: Fretless Bass + Guitar Mute (skanking)
- **Effects Focus**: Dub Echo (1/4 @ 75%), Spring Reverb

**Structure:**
```
INTRO → ONE_DROP → DUB_SECTION_1 → ROCKERS → DUB_DROP → 
BUILD_UP → BASS_INVERSION → FINAL_DUB → RE_ENTRY → OUTRO
```

**Production Tips:**
- Use Guitar Mute with Tremolo (5-8Hz rate)
- Hammond Organ with Leslie simulation
- Sub-bass layer at 20-40Hz
- Ghost kick notes (every 4 bars)
- Inverted bassline in second half

---

### **2. DUB TECHNO (135 BPM, E Minor)**

**Characteristics:**
- **Four-on-Floor**: Kick every quarter beat (techno standard)
- **Hypnotic Bass**: Repetitive E minor pattern with filter sweeps
- **Golden Ratio**: 135 BPM ÷ φ = 83 BPM (connected to dub reggae)
- **Key Instruments**: Minimal synth, filtered percussion echoes
- **Effects Focus**: Long echo (1/4-1/2), heavy filtering, saturation

**Structure:**
```
BUILD → DROP → PERC_LEDS → FILTER_SWEEP → BASS_CHANGE → 
PEAK → DECAY → BREAKDOWN
```

**Production Tips:**
- Use LFO on bass filter frequency (0.5-2Hz rate)
- Add white noise hits for texture
- Occasional offbeat kicks for syncopation
- Multiple delay returns with different times
- Plugin deep reverb layer behind

---

### **3. DEEP HOUSE (124 BPM, G# Minor)**

**Characteristics:**
- **Swing Pocket**: 20ms swing on offbeats (house groove)
- **Groovy Bass**: G# minor with melodic patterns
- **Golden Ratio**: 124 BPM × φ = 200 BPM (connected to other dance genres)
- **Key Instruments**: Electric piano, organ, vocal samples
- **Effects Focus**: Dubby delays, warm room reverb, tape compression

**Structure:**
```
BUILD → DROP → PERC_LEDS → MOTIF → BASIS → 
BUILD_UP → PEAK → DECAY → COMPRESS
```

**Production Tips:**
- Use hi-hats on offbeats with velocity variation
- Add deep sub-bass layer (40-60Hz)
- Use electric piano chords for melody
- Warm compression (2:1 ratio, soft knee)
- Tape delay withEQ filtering

### **6. TRAP (140 BPM, C Minor)**

- **"Pads provide space"** - Harmonic depth completes picture
